# 📚 電阻切換記憶體自學講義

**Resistive Memory: A Self-Study Course**

從一個會改變電阻的元件出發，慢慢走到材料機制、陣列設計、量測判讀與運算應用。這份教材以繁體中文與英文整理，適合搭配參考書閱讀，也可以依主題查找。

🗂️ **整本閱讀**：[繁體中文合訂講義](zh-TW/combined-handout.pdf) · [English combined handout](en/combined-handout.pdf)

## 怎麼使用

- **投影片 / Slides**：16:9 教用播放版。
- **講義 / Handout**：A4 直式上下雙拼，圖格標有對應的教用投影片頁碼，方便課堂與紙本對照。
- **練習 / Exercises** 與 **詳解 / Solutions**：每章各自獨立，可先試作，再對照推導。

合訂講義收錄下方八個單元；練習與詳解請從各單元進入。內容持續對照參考書檢查與補充。
